# 项目评审与健壮性修复

本轮检查覆盖 core 配置/清单、宿主运行时与包工具、控制通道及设置面板的主要路径，
结合现有测试、静态检查与无合成器 CLI 验证。不是完整安全审计，也不代表已排除所有 bug。

## 已修复

| 问题 | 修复与回归验证 |
|---|---|
| 清单允许包名 `.`/`..`，卸载接受任意路径，可能操作仓库外目录 | 清单与卸载共用单路径组件包名校验；测试非法名称与绝对/相对越界路径 |
| 安装先删除旧包，复制/解压失败会损坏旧安装，从已安装目录重装会删除源 | 同文件系统暂存完整包后替换，替换失败尝试恢复；覆盖自身重装、坏符号链接、ZIP 路径穿越失败保留原包。目录遍历错误不再被忽略，拒绝符号链接及特殊文件 |
| kind/package 替换失败丢弃旧宠物；原地 reload 失败却记录为已应用，后续不再重试 | 保留旧 slot 与配置，记录失败并允许重试；成功/禁用后清除旧错误，不重复累积 |
| Bongo reload 重建对象后丢失稳定实例 ID | runtime 在成功 reload 后重新赋予配置 ID；测试跨 reload 保持 `stable-cat` |
| `i32::MIN.abs()` 在边距校验中溢出 | 配置及控制通道使用闭区间判断；测试极端值和合法边界 |
| 非 ASCII 颜色按字节切片可能 panic | demo、GUI 颜色选择器、XPM 颜色解析先校验 ASCII；覆盖 `#猫猫` 等输入 |
| XPM 短行/Unicode 像素行越界，图像长度计算溢出，行尾逗号像素被删除 | 校验维度、行长度与 ASCII，检查乘法及分配；保留引号内逗号像素 |
| 静止预览仍每 100ms 重绘、降采样并上传纹理 | 仅首帧或 runtime 报告变化时递增帧标记；测试纹理 ID 复用及显式刷新 |

没有新增依赖版本：`tempfile` 已在锁文件和离线缓存中，此次从宿主测试依赖移到正式依赖，
用于安全创建安装暂存目录。未全仓格式化。

顺带修正文档与代码的偏差：`ARCHITECTURE.md` §15 原先仍将已落地的 G3 画布/预览列为待做。

## 实际验证

所有 Cargo 命令均使用 `CARGO_HOME=$PWD/.cargo-home` 和 `--offline`。

- `cargo build --offline`：通过。
- `cargo test --offline`：**196 项通过**（宿主 109、core 40、settings 单测 36、集成测试 11），相对基线新增 10 项测试，并扩展既有颜色测试。
- `cargo clippy --offline --all-targets`：通过，仍报告已有样式告警；`-D warnings` 不通过，未为清告警修改无关代码。
- `cargo tree --offline -p petweave`：无 egui/eframe/GTK/winit。
- `git diff --check`：通过。
- CLI 冒烟测试（独立临时 `XDG_DATA_HOME`，不触及用户包仓库）：
  - Unicode 非法颜色 demo 成功生成 256×256 预览（使用默认颜色）。
  - blinky 打包 → ZIP 安装 → 从已安装目录重装 → 卸载成功。
  - blinky XPM 导入 PNG 成功。
  - `uninstall ..` 与 `margin_top = -2147483648` 返回明确错误，无 panic。

## 尚未覆盖的边界

- 未启动真实 Wayland 宿主或 GUI；输出热插拔、拖拽、缩放和实际 CPU/RSS 仍需桌面回归。
  预览修复只验证了静止帧的纹理复用，没有重新测量 GUI CPU。
- 包安装的暂存/恢复不是断电事务，也没有多进程安装锁；ZIP 总解压大小、资源尺寸与 Lua
  运行预算仍值得进一步做恶意输入/资源耗尽测试，不应把本轮改动视作不可信包的完整隔离。
- 控制服务仍使用无界客户端输出队列；GUI 的 socket 在 connect 后才设为非阻塞。
  慢客户端背压、积压连接与超时属于后续协议加固重点。
