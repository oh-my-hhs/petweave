# Bongo Cat assets

The four PNG frames (`bongo-cat-{both-up,left-down,right-down,both-down}.png`)
are the classic Bongo Cat artwork, copied from the
[wayland-bongocat](https://github.com/saatvik333/wayland-bongocat) project
(MIT License, © the wayland-bongocat contributors; original cat artwork by
[@Shreyabardia](https://github.com/Shreyabardia)).

Bongo Cat was originally created by [StrayRogue](https://twitter.com/StrayRogue)
and [DitzyFlama](https://twitter.com/DitzyFlama).

The source tree also carries SVG versions under
`Reference/wayland-bongocat/assets/new/` (not shipped here); once a network
connection is available we intend to switch rendering to resvg + these SVGs
for pixel-perfect scaling.
